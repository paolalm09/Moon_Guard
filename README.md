This is a little game called MoonGuard it was made for the hackathon hosted by Nasa Space Apps
it was made with HTML, CSS, and Javascript
my friend designed the game while I coded it and made the logic work

The game starts off with a short into video and then the player is put into a lunar base mission where they open up their dashboard and complete Daily Tasks. The mission spans across 6 Days where the Day 6 is when they get to go home
Each choice made in the game affects their supplies: Power, Oxygen, and Water
